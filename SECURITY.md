# Security policy

LFAI WORLD is built so that the factory never holds the keys.

- **Never stored by the factory or by us:** passwords, two-factor codes, GitHub tokens, AI-provider keys. Wiring keys live only in the owner's own GitHub Actions secrets.
- **Never published:** originals, the ledger, drafts. Only approved chapters reach the public showroom, after an automated personal-data check at the gate (WC-04) and a human decision.
- **On this account:** secret scanning with push protection, Dependabot alerts and a protected default branch are enabled on every public repository.

## Reporting a vulnerability
Use **Report a vulnerability** on the Security tab of this repository (private vulnerability reporting). Please do not open a public issue. We acknowledge reports within 3 working days.
